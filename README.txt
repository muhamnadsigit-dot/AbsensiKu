# AbsensiKu - Prototype Aplikasi Absensi Karyawan

Aplikasi web sederhana berdasarkan konsep pada gambar:
- Absensi karyawan online
- Atur jadwal kerja
- Monitoring kunjungan/kehadiran karyawan
- Kelola data karyawan
- Monitoring progres pekerjaan

## Cara menjalankan

Tidak membutuhkan database atau instalasi khusus.

1. Extract file ZIP.
2. Buka folder `aplikasi_absensi_karyawan`.
3. Klik dua kali `index.html`, atau buka folder dengan VS Code.
4. Jika menggunakan VS Code, bisa menjalankan `index.html` dengan Live Server.

## Struktur file

- `index.html` -> tampilan utama
- `style.css` -> desain dan responsive mobile
- `script.js` -> data demo dan fungsi tambah/hapus absensi serta karyawan

## Catatan

Versi ini masih prototype/front-end sehingga data belum tersimpan ke database.
Cocok untuk direview terlebih dahulu sebelum dikembangkan menjadi aplikasi yang lebih lengkap.
